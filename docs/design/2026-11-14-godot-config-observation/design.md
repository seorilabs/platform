# Godot 설정 조회의 통신 결과 구분

My Little Parasite의 승인된 [잔여 출시 설계](https://github.com/seorilabs/my-little-parasite/blob/ac95d68d7995bc602fcc310e160edff7c8fd1e0f/docs/design/2026-11-13-launch-completion/design.md)에서 오프라인·연결 실패·재시도와 공통 원본 수정을 승인받았다. 사용자 응답은 “승인”이며 별도 SDK 공개 태그·운영 배포는 이 변경에 포함하지 않는다.

기존 `fetch_config`는 장애 때도 캐시나 기본값으로 시작할 수 있도록 `ok:true`를 반환한다. 이 동작을 유지하면서 `networkOk`를 추가해 방금 HTTP 조회가 성공했는지 구분한다. 설정 캐시와 기존 콜백 필드의 의미를 바꾸지 않는다. 제품은 이 값을 연결 상태 안내에 쓰고, 네트워크 실패를 새 운영 설정이나 강제 업데이트 해제로 처리하지 않는다.

검사는 실제 Godot SDK에 전송 경계만 주입해 초기 장애·성공·캐시가 있는 장애를 실행한다. 변경 전 4개 중3실패, 변경 후4통과와 기존 전체 smoke를 확인한다. 사용자 계정·기기·운영 서버에 접근하지 않는다. L1 개발 환경이며 파일 기반 원본과 새 probe를 보존한다. 공개 API의 선택 필드 추가이므로 기존 소비자 호환을 유지하며 계약 버전을 올리거나 새 릴리스를 만들지 않는다.
